# 고흥FC 드림 프로젝트

고흥대서중학교 축구부 학생선수의 3년을 키우는 웹 육성 시뮬레이션입니다.
입학부터 졸업, 엔딩까지 3년 전체를 플레이할 수 있습니다.

## 학교생활 업데이트
- 1년 45주. 3월 개학 → 7월 2주 대서어울림문화캠프·방학식 → 7월 3주 하계훈련(합숙) → 하계대회 → 9월 개학 → 12월 스키캠프·봉두예술제 → 1월 1주 졸업식·방학식 → 1월 2주 동계훈련(합숙) → 동계대회
- 정기시험: 5월 초, 7월 초, 10월 초, 12월 초 (중1 1학기는 자유학기라 수행평가 주간)
- 학교 행사: 중1 수련회(4월), 중2 싱가포르 국제교류(5월), 중3 수학여행(11월), 매년 고흥 연합 체육대회(5월), 스키캠프, 봉두예술제, 졸업식
- 방학 중에는 수행평가 준비, 학교 활동을 고를 수 없습니다. 합숙 주간에는 훈련 효과 1.2배, 피로 1.25배
- 3학년 선배들은 1월 졸업식에서 떠나고, 동계대회는 남은 학년으로 뜁니다. 주인공은 중3 1월 졸업식에서 엔딩을 봅니다
- 하계대회는 조별리그 → 8강, 동계대회는 조별리그 → 4강
- 류봉두 선생님 장면 7개와 선생님과의 관계(팀 화면 → 관계). 졸업식 날 받는 편지가 관계에 따라 달라지고 엔딩 화면에 나옵니다
- 경기 중 부상(드물게). 피로가 높거나 '유리몸'이면 더 자주. 스키캠프 상급 코스, 체육대회 계주에서도 다칠 수 있습니다
- 얻는 특성 10가지: 우승 DNA, 해결사, 에이스, 통곡의 벽, 플레이메이커, 오뚝이, 강철 체력, 문무겸비, 승부사, 리더십. 조건을 채우면 특성이 생기고 능력치가 바로 오릅니다. 선수 화면 → 특성에서 조건을 볼 수 있습니다
- 학교 행사 날짜는 `data/calendar.js`의 `SCHOOL_DAYS`, 장면과 선택지는 `data/events.js`에서 고칠 수 있습니다

## C 작업에서 추가된 것
- 진로 일정: 중3 9월 1주 감독님 진학 이야기 → 10월 4주 진학 상담(학교 선택, 되돌릴 수 없음) → 12월 2주 U-15 대표팀 명단 발표 → 졸업 엔딩
- 진학 조건: 능력치에 감독님 추천서, 생활태도, 학업, 고교 관심도, 전국대회 성적이 더해지고 빠집니다. 축구부 없는 일반고 진학도 고를 수 있습니다
- 엔딩 14종(전설·S·숨겨진·A·B·C·D 등급), 엔딩 도감(이 기기에 기록). 타이틀 화면에서 볼 수 있습니다
- 감독님 말투: 순위나 능력치 숫자를 직접 말하지 않고 돌려서 말합니다
- 녹동 할머니 댁 이벤트 삭제. 해변 모래 훈련은 경기에 진 다음 주에 60% 확률로 나옵니다
- 화면 전체를 FC 시리즈 느낌으로 다시 꾸몄습니다: 타이틀(화면을 누르면 메뉴), 선수 카드(능력치에 따라 동·은·금·특급), 다음 경기 카드, 아이콘 메뉴
- 미니게임 그래픽: 관중석과 골키퍼가 있는 골문, 등번호 유니폼, 흘러가는 잔디와 수비수·콘, 바벨. 결과는 큰 등급 글자로 나옵니다

## B 작업에서 추가된 것
- 이벤트 32개 (학교생활, 축구부, 가족). 한 주가 끝나면 약 3분의 1 확률로 하나 일어나고, 선택에 따라 능력치·피로·사기·감독 신뢰·관계가 바뀝니다
- 관계: 단짝 친구, 라이벌, 멘토 선배, 챙기는 후배(중2부터). 팀 화면 "관계" 탭
  - 친구 70 이상이면 사기가 잘 안 떨어짐 / 라이벌과 능력치 차이 5 이내면 훈련 효율 +5%
  - 멘토 선배 70 이상이면 매주 집중력·팀워크 상승 / 후배 60 이상이면 팀워크 상승
  - 관계 행동 4개: 라이벌과 1대1, 선배와 개인 훈련, 후배 챙기기, 친구와 놀기
  - 선배가 졸업하면 다음 선배가 멘토가 되고, 졸업 메시지가 옵니다
- 중3 3월 2주차 주장 선거 (감독 신뢰, 팀워크, 생활태도, 관계로 결정)
- 훈련 미니게임 4종: 슈팅(조준), 패스(순서대로 누르기), 드리블(피하기), 웨이트(타이밍). 등급 S ×1.5, A ×1.25, B ×1.0, C ×0.8. 능력치가 높을수록 쉬워지고, 홈 화면에서 끌 수 있습니다

## 그 전 수정
- 시작: 영화 같은 도입부(건너뛰기 가능) → 감독님과 대화하며 입단 (이름, 사진, 포지션, 주발, 성장 유형, 기초 체력 측정표, 등번호)
- 메시지: 경기 전 상대 분석, 경기 후 감독님 면담(내 선택과 능력치 수치로 피드백), 단톡방 경기 기록(득점자, 점유율, 순위), 6주 훈련 점검, 시험 예고, 피로·사기·부상·성장 관련 메시지
- 경기: 양 팀 22명이 공 위치에 따라 움직이고, 패스 전개 7가지(빌드업, 측면 크로스, 롱볼, 역습, 코너킥, 원투, 중거리)를 선수 이름과 함께 중계. 골 장면 연출, 하프타임·종료 때 경기 기록

- 진학 연습경기: 중3 4월·6월 고정, 중2 2학기 연습경기는 절반 확률로 고교 팀. 고교 감독 관전, 몸싸움 불리, 학교별 관심도와 입학 제안

## 1단계에서 만든 것
- 선수 만들기: 이름, 얼굴, 포지션(FW·MF·DF), 주발, 성장 유형, 신체 측정, 특성, 코치 평가
- 주간 행동: 평일 2칸 + 주말 1칸, 17가지 행동 (개인훈련·단체훈련·학교생활·휴식·재활)
- 성장: 성장 유형별 학년 배율, 잠재력, 피로·사기에 따른 훈련 효율
- 신체 성장: 매년 3월·9월 측정, 급성장기 성장통
- 학업 제재: 40 미만 경고 → 30 미만 학부모 상담 → 20 미만 대회 출전 제한 → 10 미만 공식 경기 출전 정지
- 시험: 중간·기말고사 (중1 1학기는 자유학기라 수행평가 주간)
- 부상: 발목, 햄스트링, 무릎, 성장통
- 학년 전환: 선배 졸업, 후배 입단, 등번호 (중1 30~99 / 중2 13~29 / 중3 직접 선택, 7·9·10번 경쟁)
- 메시지함 (감독님, 단톡방, 담임 선생님, 엄마, 의무 기록)
- 저장: 자동 저장 + 슬롯 3개 + 다른 기기로 옮기는 저장 코드

## GitHub Pages에 올리는 방법
1. GitHub에서 새 저장소(Repository)를 만듭니다. 예: `goheung-fc`, Public
2. **Add file → Upload files** 를 눌러 이 폴더 안의 내용물을 전부 끌어다 놓고 **Commit changes**
   (폴더째가 아니라 `index.html`이 저장소 맨 위에 오도록 올려야 합니다)
3. 저장소의 **Settings → Pages** 로 가서
   Source: **Deploy from a branch**, Branch: **main**, 폴더: **/(root)** → **Save**
4. 1~2분 뒤 같은 화면 위쪽에 `https://아이디.github.io/goheung-fc/` 주소가 뜹니다. 이 주소를 학생들에게 나눠 주시면 됩니다.

## 내 컴퓨터에서 확인하기
압축을 풀고 `index.html`을 더블클릭하면 바로 열립니다. (크롬·엣지 권장)
이때는 모든 코드를 한 파일로 묶은 `js/game.bundle.js`가 쓰입니다.

- 압축을 풀지 않고 zip 안에서 바로 열면 안 됩니다. 꼭 "압축 풀기"를 먼저 해 주세요.
- 더블클릭으로 연 게임은 묶어 둔 시점의 내용으로 돌아갑니다. `data/` 파일을 고친 내용은 GitHub Pages에 올린 쪽에 바로 반영되고, 내 컴퓨터 쪽은 `node tools/bundle.mjs`를 다시 실행해야 반영됩니다.
- 내 컴퓨터에서 한 저장과 GitHub 주소에서 한 저장은 서로 따로입니다.

## 밸런스 확인 (개발용)
`node tools/simulate.mjs 300 smart` — 300판을 자동으로 돌려 성장 유형별 결과를 보여 줍니다.
