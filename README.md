# 고흥FC 드림 프로젝트

고흥대서중학교 축구부 학생선수의 3년을 키우는 웹 육성 시뮬레이션입니다.
입학부터 졸업, 엔딩까지 3년 전체를 플레이할 수 있습니다.

## 오프닝·화면 크기·경기 장면 업데이트

- 오프닝 문구 새로 씀. 마지막 장면 "3년 / 미래는 어떻게 바뀔지 모른다."는 화면 한가운데에서 한 글자씩 나타남
- 화면 크기 점검: PC(1280~1920), 태블릿(세로·가로), 휴대폰(세로·가로·작은 화면), 전체화면 크기에서 잘리는 곳 수정
  - 세로 화면 경기: 전광판·경기장·중계·선택지가 한 화면에 들어오도록 경기장 크기 자동 조절
  - 휴대폰 가로: 선택지를 고를 때 중계를 접어 공간 확보, 미니게임·타이틀 크기 조절
- 경기 장면 6개 추가 (포지션별 2개): 골키퍼가 튀어나올 때(FW), 니어포스트 침투(FW), 내려앉은 수비 공략(MF), 빈 측면 커버(MF), 오프사이드 트랩(DF), 골문 앞 혼전(DF)
  - 장면마다 공이 놓이는 자리(spot)를 정해 경기장 위 점과 문장이 맞도록 함

## 이벤트 그림·미니게임 업그레이드

- 새 이벤트 그림 8장: 감독실(ev_office), 국어 교실(ev_classroom), 우승 회식(ev_dinner), 라커룸 생일(ev_birthday), 집 생일(ev_birthday_home), 준우승 자장면(ev_jjajang), 우승 환영(ev_welcome), 수학여행(ev_schooltrip). 해변 훈련에는 bg_sea 연결
- 패스 훈련: 야간 경기장 위에서 본 화면. 공이 실제로 굴러가거나(땅볼) 떠서(롱패스) 날아가고, 받는 선수 발밑에 파동
- 드리블 훈련: 내 등 뒤에서 본 원근 화면. 수비가 멀리서 달려와 커지고, 부딪히면 태클·흙먼지. 화면 왼쪽·오른쪽을 눌러도 움직임
- 웨이트 훈련: 체력실에서 옆으로 본 스쿼트. 원이 줄어드는 동안 앉았다가, 판정에 따라 힘차게(완벽)·천천히(좋음)·주저앉음(실패)
- 판정 규칙·등급 기준·난이도(LV.1~4)는 예전과 같음
- 오프라인 모드: 바뀐 파일만 다시 받도록 개선 (sw.js 의 BUILD 값은 node tools/bundle.mjs 가 자동으로 바꿈)

## 관계 무작위 배정

- 라이벌·멘토 선배·챙기는 후배를 같은 포지션 후보 중 무작위로 정함 (판마다 달라짐). 단짝 친구는 원래대로 동기 중 무작위
- 멘토 선배가 졸업할 때 바뀌는 다음 선배도 같은 포지션 중 무작위

## 오프라인 모드

- 인터넷이 될 때 GitHub 주소로 한 번 접속하면 게임 파일·그림·글꼴이 기기에 저장되고, 그 뒤로는 비행기 모드에서도 열림 (아이폰 사파리 포함)
- 아이폰은 사파리 → 공유 → "홈 화면에 추가" 후 그 아이콘으로 실행하는 것을 권장 (홈 화면 아이콘과 사파리는 저장 진행이 따로임)
- 코드·데이터는 인터넷이 되면 항상 최신 파일을 받으므로, data/ 파일을 고쳐 올리면 바로 반영됨
- 관련 파일: sw.js(고칠 필요 없음), offline-files.js(node tools/bundle.mjs 가 자동으로 만듦)
- 파일을 더블클릭해서 여는 방식은 원래처럼 인터넷 없이 동작 (오프라인 모드와 무관)

## 축하·생일 업데이트

- 우승 축하 이벤트: 주말리그 우승은 회식(고깃집 또는 운동장 치킨), 전국대회 우승은 학교 앞 환영 행사, 준우승은 자장면 회식
- 생일: 입단할 때 생일(월·일)을 고름. 생일 주간에는 단톡방·엄마·아빠 축하 메시지, 사기 +8, 피로 -8, 라커룸(방학이면 집) 생일 이벤트
- 생일 주간에 선발로 나가면 경기 시작 대사, 골을 넣으면 감독님·단톡방 반응이 따로 나옴
- 생일은 능력치를 직접 올리지 않음 (류봉두의 축복과 겹치지 않게)
- 경기 화면 점검: 골 뒤 센터서클 재시작, 교체 때 공이 순간이동하지 않게, 선수 점이 경기장 밖으로 밀려나지 않게, 팀 이름 줄바꿈 수정

## 후배 추가·축복 업데이트

- 후배 선수 5명 추가: 김하유(DF)·최인후(MF)는 1년 후배, 권송(DF)·이만송(MF)·강범창(FW)은 2년 후배
- 류봉두의 축복: 류봉두 선생님과 관계 70 이상이면 2학기(9~12월) 중 1년에 한 번, 무작위 능력치 하나가 오름. 12월까지 안 나오면 12월에 반드시 나옴
- 해트트릭, 첫 골, 첫 선발, 부상 복귀전, 경고, 결승, 중학교 마지막 경기 등 상황에 맞는 감독님 면담·단톡방·부모님 메시지 추가
- 총점검: 경기 기록, 이벤트 시기, 존댓말, 메시지 조건 등 오류 수정

## 1단계에서 만든 것
- 선수 만들기: 이름, 얼굴, 포지션(FW·MF·DF), 주발, 성장 유형, 신체 측정, 특성, 코치 평가
- 주간 행동: 평일 2칸 + 주말 1칸, 17가지 행동 (개인훈련·단체훈련·학교생활·휴식·재활)
- 성장: 성장 유형별 학년 배율, 잠재력, 피로·사기에 따른 훈련 효율
- 신체 성장: 매년 3월·9월 측정, 급성장기 성장통
- 학업 제재: 40 미만 경고 → 30 미만 학부모 상담 → 20 미만 대회 출전 제한 → 10 미만 공식 경기 출전 정지
- 시험: 중간·기말고사 (중1 1학기는 자유학기라 수행평가 주간)
- 부상: 발목, 햄스트링, 무릎, 성장통
- 학년 전환: 선배 졸업, 후배 입단, 등번호 (중1 30~99 / 중2 13~29 / 중3 직접 선택, 7·9·10번 경쟁)
- 메시지함 (감독님, 단톡방, 담임 선생님, 엄마, 의무 기록)
- 저장: 자동 저장 + 슬롯 3개 + 다른 기기로 옮기는 저장 코드

## GitHub Pages에 올리는 방법
1. GitHub에서 새 저장소(Repository)를 만듭니다. 예: `goheung-fc`, Public
2. **Add file → Upload files** 를 눌러 이 폴더 안의 내용물을 전부 끌어다 놓고 **Commit changes**
   (폴더째가 아니라 `index.html`이 저장소 맨 위에 오도록 올려야 합니다)
3. 저장소의 **Settings → Pages** 로 가서
   Source: **Deploy from a branch**, Branch: **main**, 폴더: **/(root)** → **Save**
4. 1~2분 뒤 같은 화면 위쪽에 `https://아이디.github.io/goheung-fc/` 주소가 뜹니다. 이 주소를 학생들에게 나눠 주시면 됩니다.

## 내 컴퓨터에서 확인하기
압축을 풀고 `index.html`을 더블클릭하면 바로 열립니다. (크롬·엣지 권장)
이때는 모든 코드를 한 파일로 묶은 `js/game.bundle.js`가 쓰입니다.

- 압축을 풀지 않고 zip 안에서 바로 열면 안 됩니다. 꼭 "압축 풀기"를 먼저 해 주세요.
- 더블클릭으로 연 게임은 묶어 둔 시점의 내용으로 돌아갑니다. `data/` 파일을 고친 내용은 GitHub Pages에 올린 쪽에 바로 반영되고, 내 컴퓨터 쪽은 `node tools/bundle.mjs`를 다시 실행해야 반영됩니다.
- 내 컴퓨터에서 한 저장과 GitHub 주소에서 한 저장은 서로 따로입니다.
